Mitra OS (Beleaf Farms)

I was fully responsible for designing the user experience and interface of this application, from conducting UX research to creating wireframes and interactive prototypes. This mobile app was developed to help farmers manage and monitor their crops throughout the entire lifecycle — from planting to harvest. Its key features include:

  • Crop Tracking: Monitor the status and progress of each crop in detail, from planting to harvesting.
  • Dosing Machine Control: For farmers who own dosing machines, the app enables precise adjustment of fertilizer, vitamin, or nutrient doses for each crop.
  • Weather Station: Provides up-to-date weather forecasts as well as historical weather data to support better crop care decisions.
  • Agricultural Marketplace: Allows farmers to order fertilizers, vitamins, and herbicides directly from Beleaf Farms through the app.

With an intuitive interface and user experience designed specifically for the farming context, the application aims to improve efficiency, reduce risks, and support data-driven decision-making for farmers.

Full description: Mitra OS is a comprehensive operating system for Beleaf Farms, designed to streamline farm management, financial tracking, and team collaboration. The recent redesign focused on improving usability, visual clarity, and integrating new fintech features for seamless operations.
